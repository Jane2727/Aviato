# Документация по требованию «Дублирование объявлений (Сервис Draft)»

## Frontend логика

### Общий обзор

Draft (Черновик) — временное объявление со статусом DRAFT, не видимое другим пользователям

### Экраны (страницы)

- Страница редактирования черновика
  /drafts/:draftId/edit

### API-эндпоинты

- Создание черновика: POST /api/v1/listings/{id}/duplicate
- Получение данных черновика: GET /api/v1/drafts/{draftId} (также продлевает TTL черновика на 7 дней)
- Обновление черновика: PUT /api/v1/drafts/{draftId} (также продлевает TTL черновика на 7 дней)
- Публикация черновика: PUT /api/v1/drafts/{draftId}/publish
- Удаление черновика: DELETE /api/v1/drafts/{draftId}

### Навигационные переходы

Карточка объявления (владельца)

- [Клик "Создать копию"]
- POST /api/v1/listings/{id}/duplicate
- [201] редирект на /drafts/{draftId}/edit
- [4xx/5xx] показать уведомление с ошибкой

Страница редактирования черновика (копии объявления)
/drafts/{draftId}/edit

- [Клик "Сохранить изменения"]
  - PUT /drafts/{draftId}/publish
  - [200] уведомление "Объявление отправлено на модерацию" редирект в /my-ads
  - [400 category] подсветить поле категории, показать inline-error
  - [409 media] показать уведомление "Медиа ещё обрабатываются"
  - [409 duplicates] открыть AntiSpamModal

- [Клик "Отменить и выйти"]
- открыть CancelModal
- [Confirm] DELETE /drafts/{draftId} редирект в /my-ads

### Экраны и переходы

#### Экран «Исходная Карточка объявления»

На экране «Карточка объявления» добавить кнопку «Создать копию» в меню действий объявления.
Для десктопа добавляем в список меню, для мобильнной версии - отдельной кнопкой
Отрисовка аналогичная как у других пунктов меню.

Копию можно создавать только из своего объявления в статусе «Активно» (ACTIVE) или «В архиве» (ARCHIVED), поэтому кнопка видна только если:
ad.owner_id === currentUser.id && (ad.status === 'ACTIVE' || ad.status === 'ARCHIVED')

Для остальных статусов (DRAFT, MODERATION, DELETED, BANNED) кнопка не отображается.

При клике на «Создать копию» вызываем API без дополнительных модалок

Состояние кнопки (аналогично другим пунктам меню):

- idle: обычное состояние.
- loading: спиннер внутри кнопки, disabled (спиннер только для отдельной кнопки, в мобильной версии).
- success: не показываем, сразу редирект.
- error: уведомление с текстом ошибки.

#### Экран «Редактирование черновика» (/drafts/:draftId/edit)

За основу взят дизайн страницы редактирования объявления (подробнее на макетах Figma).

Важные нюансы и добавления:

1. Если выбрана категория, которая теперь недоступна draft.category.is_active === false, показываем уведомление:
   "Категория недоступна. Пожалуйста, выберите новую категорию для публикации"
   Кнопка «Сохранить изменения» заблокирована (disabled={true}) до момента выбора корректной категории

2. Если у оригинального объявления были промо-опции, показываем баннер "Промо-опции не были скопированы. Вы можете добавить их заново перед публикацией"
   И кнопку "Добавить промо" рядом

3. Поля предзаполняются из GET /drafts/{draftId}

4. Раздел с видео, если оно ещё копируется status === 'PROCESSING', показываем плейсхолдер label="Копируем видео..."
   Статус отображается только по черновику в целом (draft.media_status), детализация по отдельным файлам не показывается.
   Polling статуса медиа:

const { data: draft } = useDraft(draftId, {
refetchInterval: (query) =>
query.state.data?.media_status === 'PROCESSING' ? 3000 : false,
});

5. Продление TTL происходит автоматически при каждом обращении к черновику, как при открытии страницы (GET), так и при сохранении изменений (PUT). Отдельной кнопки «Сохранить черновик» не предусмотрено, весь UI ограничивается кнопками «Сохранить изменения» и «Отменить и выйти». Пользователь видит актуальный expires_at, полученный из ответа GET/PUT.

6. Кнопки в футере «Отменить и выйти» и «Сохранить изменения»

- Кнопка «Сохранить изменения» задизейблена если disabled={!isFormValid || isPublishing || !category?.is_active || hasProcessingMedia}
  - !isFormValid - ошибки валидации формы
  - isPublishing - идет запрос публикации
  - !category?.is_active - категория неактивна
  - hasProcessingMedia - медиа в процессе загрузки

7. Информирование об истечении TTL: если до expires_at остаётся менее 24 часов, показываем баннер с оставшимся временем. Email/push-уведомление за 1 день до истечения TTL инициируется Backend (Notification Service), на фронте отдельного действия для его отправки не требуется.

#### Модальное окно CancelModal (переиспользуем стандартную модалку подтверждения)

С текстом "Отменить редактирование? Черновик будет удалён. Это действие нельзя отменить."
И кнопки "Остаться" и "Удалить черновик"

При клике на "Удалить черновик" DELETE /drafts/{draftId} - редирект в /my-ads

#### Модальные окна AntiSpamModal и CategoryPickerModal

Переиспользуем готовое решение проекта

### Маппинг HTTP-кодов

Код: 201
Ситуация: Черновик создан
UI: Редирект на /drafts/{id}/edit

Код: 200
Ситуация: Успех, Черновик отправлен на модерацию
UI: Уведомление "Объявление отправлено на модерацию" + редирект в /my-ads

Код: 400
Ситуация: Категория неактивна (CATEGORY_INACTIVE)
UI: Inline-error у поля категории, alert сверху

Код: 400
Ситуация: Исходный статус не подходит для копирования (INVALID_SOURCE_STATUS)
UI: Уведомление «Дублирование доступно только для объявлений в статусе «Активно» или «В архиве»»

Код: 400
Ситуация: Ошибки формы (VALIDATION_ERROR)
UI: Подсветка полей, скролл к первой ошибке

Код: 403
Ситуация: Нет доступа
UI: 403 страница

Код: 404
Ситуация: Черновик не найден
UI: 404 страница

Код: 409
Ситуация: Медиа ещё копируются (MEDIA_PROCESSING)
UI: Уведомление «Подождите, медиа обрабатываются»

Код: 409
Ситуация: Анти-спам (DUPLICATES_FOUND)
UI: AntiSpamModal

Код: 429
Ситуация: Rate limit
UI: Уведомление «Слишком много запросов, попробуйте позже»

Код: 500
Ситуация: Ошибка сервера
UI: Уведомление «Произошла ошибка, попробуйте позже»

### События аналитики

Триггер: Клик «Создать копию»
Событие: draft_create_click
Payload: { source_listing_id }

Триггер: Успешный ответ 201
Событие: draft_created
Payload: { draft_id, source_listing_id }

Триггер: Ошибка создания
Событие: draft_create_error
Payload: { source_listing_id, error_code }

Триггер: Открытие страницы редактирования
Событие: draft_edit_open
Payload: { draft_id, media_count, has_promo_warning }

Триггер: Клик «Сохранить изменения»
Событие: draft_edit_save
Payload: { draft_id }

Триггер: Успешная публикация
Событие: draft_publish_success
Payload: { draft_id }

Триггер: Ошибка публикации
Событие: draft_publish_error
Payload: { draft_id, error_code }

Триггер: Клик «Отменить и выйти»
Событие: draft_cancel_click
Payload: { draft_id }

Триггер: Подтверждение удаления
Событие: draft_cancel_confirm
Payload: { draft_id }

### Доступность (a11y)

Стандартно на проекте, проверь соответствие:

- Все кнопки имеют aria-label.
- Модальные окна role="dialog", aria-modal="true", фокус ловится внутри (focus trap).
- Ошибки формы aria-invalid="true" + aria-describedby на текст ошибки.
- Состояние загрузки aria-busy="true" + aria-live="polite" для статусов.
- Клавиатурная навигация: Tab по всем интерактивным элементам, Esc закрывает модалки.

## Тест-план для QA

### Smoke-тесты

Создать копию объявления: открывается страница редактирования с предзаполненными данными.
Изменить название, нажать «Сохранить»: объявление создано.
Нажать «Отменить и выйти», подтвердить: черновик удалён.

### Функциональные тесты

- Копирование с 10 фото и 1 видео (50 МБ).
- Удаление исходного объявления: копия остаётся рабочей.
- Редактирование черновика: TTL продлевается.
- Открытие черновика без изменений (только GET): TTL продлевается.
- Попытка создать копию из объявления в статусе MODERATION/DELETED/DRAFT/BANNED: кнопка «Создать копию» не отображается.
- Попытка опубликовать с неактивной категорией: блокировка.
- Публикация с дублями: модалка анти-спама.

### Edge-cases

- Две вкладки с одним черновиком.
- Потеря сети во время сохранения.
- Видео в оригинале ещё в статусе PROCESSING.
- Попытка скопировать чужое объявление (IDOR) 403.
- Попытка скопировать объявление в неразрешённом статусе (не ACTIVE/ARCHIVED), идёт прямой вызов API в обход UI, ожидается 400 INVALID_SOURCE_STATUS.
